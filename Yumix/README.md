# Yumix — Favorites Roulette

A small iOS app that shows a random product from each fridge shelf: dairy, fruits and vegetables. Tap **Randomize** to update all three shelves. The same product never appears twice in a row on the same shelf.
Ten favorites in total. Each has an image, a title and a description (calories per 100 g).

## Tech

- Xcode, iOS App template
- Interface: Storyboard
- Language: Swift
- Auto Layout disabled (no constraints), elements placed by coordinates

1. Open `Yumix.xcodeproj` in Xcode.
2. Choose a simulator, for example iPhone 16
3. Press **▶** (Run)
