### Array

* Add: `array.append(value)`
* Merge: `array1 + array2`

### Set

* Stores unique values.
* Add: `set.insert(value)`
* `union()` → all
* `intersection()` → common
* `subtracting()` → remove elements

### Dictionary

* Stores `key: value`.
* Access: `dictionary["key"]`
* Add/update: `dictionary["key"] = value`
* Access returns `Optional`, so `!` can unwrap it: `dictionary["key"]!`

### Nested Collection

`[String: [Int]]` = name → array of grades.

`dictionary["Arai"]![1]` → second grade.
